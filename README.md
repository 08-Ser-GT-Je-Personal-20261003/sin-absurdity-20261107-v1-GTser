## 内容与讲道要点

独立新项目，不覆盖既有讲章。约1.35万汉字，16个章节，18题详细讨论及答案。讲道两点为：

1. 他们对差役的回应（约7:45–49）。
2. 他们对尼哥底母的回应（约7:50–52）。

包括作者、受众、年代与处境、住棚节和差役背景、前后文、八节细读、箴言5章忠贞伦理、地理示意与52节文本讨论、公义听审流程、论证对照、救赎历史、圣约神学、罪—救赎—感恩、三信经比较与三项联合信条导读、记忆卡、思维导图、诗歌联系及祷告。

罪的荒谬指人在神面前以自保拒绝真理，不是智商低或精神疾病诊断。讲章不把犹太群体漫画化，不凭差役一句惊叹判定重生，不将尼哥底母程序性发言等同完整认信。箴5先按婚约与性伦理解释，再与约7联系，不把女性寓意为一切罪。

## 生成与维护

Python 3.10+，不需要第三方Python库：

```sh
python build.py
python verify.py
python audit_sources.py
python -m http.server 8767 --directory dist
```

`content.json` 存背景与讲章；`study.json` 存信条导读、短引与讨论；`build.py` 生成静态页面。修改内容后重建并提交，GitHub Actions在push至main后检查并部署Pages；Surge独立部署相同的 `dist/`。

`python verify_deploy.py` 比较两个站点与本地页面、样式和脚本。全部资源为相对路径，可运行于Pages子目录。Surge自动生成的CNAME不提交，也不进入Pages构建。不要在仓库、产物或日志中保存密码和令牌。
